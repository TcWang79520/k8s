# tools — 產生 `CKAD-Prepare.html`

把散在各處的 markdown 筆記合併成**單一份可離線閱讀的 HTML**（零外部請求，沒有 CDN、沒有網路字型，用瀏覽器直接開檔案就能看）。

## 怎麼跑

```bash
python tools/build-html.py
```

在 repo 任何位置執行都可以，腳本會自己定位 repo 根目錄。改完 `.md` 之後重跑一次，`CKAD-Prepare.html` 就會更新。

輸出範例：

```
OK docs=5 sections=42 (考古題 19 / 模擬 19) bytes=379846
```

## 要加一份新筆記

在 `build-html.py` 最上面的 `DOCS` 加一行就好：

```python
DOCS = [
    ...
    ('kodecloud/Exam-5.md', 'e5', '模擬測驗 Exam 5', 'KodeKloud'),
]
```

四個欄位分別是「markdown 相對路徑、錨點前綴、側邊欄群組名稱、群組卡上方的小標」。

**錨點前綴是必要的**：每份 exam 筆記都有自己的 `#q1`、`#q10`，合併之後會互撞。前綴會把它們變成 `#e5-q1`，各檔案內部的目錄連結也會自動跟著改寫。取一個沒被用過的短字串即可（考古題刻意留空，維持原本的錨點不變）。

## 來源 markdown 要遵守的慣例

腳本靠這些慣例判斷版面，寫筆記時照著來就會自動排好：

- `# 標題` → 該來源的群組名稱；緊接的第一段 → 群組說明。
- 接著的 `- [Q1 - ...](#q1---...)` 清單 → 該來源的題目索引卡片格。
- `## 題目N - 標題` 或 `## QN - 標題` → 一張題目卡，`N` 會變成左上角的編號徽章。
- `**題目**：`、`**解法**：`、`**驗證**：`、`**排查**：`、`**重點整理**：`、`**易錯點／踩坑筆記**：`、`**相關資源**：`、`**對應考綱 Domain**：`、`**Quick Reference**：` 等標籤 → 帶顏色的區塊。新標籤要配色的話，加到 `build-html.py` 的 `LABELS`。
- ` ```bash ` / ` ```yaml ` → 語法上色（另外支援 Dockerfile）。

> 注意：`##` 之前、目錄清單之後如果還有零散內容，它會變成飄在群組卡和第一題之間的散落文字。這類內容請補成正式的 `## QN - 標題` 段落。

## 開頭的「依 CKAD 考綱分類」總覽

頁面開頭會依官方五大 Domain 把**所有來源的題目**收攏成一份索引，每題是一個可點的膠囊（題號 + 標題 + 來源標籤），點了直接跳到該題。

歸類的資料來源有兩條：

1. **考古題**：直接讀 md 裡既有的 `**對應考綱 Domain**：` 欄位，不需要另外維護。
2. **模擬測驗**：這些筆記沒有那個欄位，改用 `build-html.py` 裡的 `MOCK_DOMAIN` 對照表，key 是 `(文件前綴, 題號)`。

新增題目時若兩邊都查不到歸類，**build 會直接中止並指名是哪一題**，不會默默漏掉；照訊息補上 md 的「對應考綱 Domain」或 `MOCK_DOMAIN` 一筆即可。

Domain 名稱、中文、權重、說明文字都在 `DOMAINS` 裡改。

## `CKAD/` 的 YAML 會自動嵌進對應題目

每題的「相關資源」區塊底下會附上可展開的檔案面板，來源有兩條規則：

1. **檔名數字前綴** —— `04-*.yaml` 歸第 4 題、`10.RBAC.yaml` 與 `10-rbac-fix.yaml` 歸第 10 題。（只套用在考古題那份）
2. **內文明確引用的路徑** —— 例如 `cronjob-1.yaml`、`limitrange.yaml` 這些沒有數字前綴的。

兩條都抓不到的，寫在 `build-html.py` 的 `EXTRA_FOR_Q`（目前只有 `CKAD/Dockerfile` → 第 3 題）。

## 檔案

- `build-html.py` —— markdown 解析、語法上色、連結重寫、輸出組裝。
- `template.html` —— 版面與樣式；`{{TITLE}}` / `{{INTRO}}` / `{{STATS}}` / `{{NAV}}` / `{{CONTENT}}` 由腳本填入。改配色、改版面都在這裡。
